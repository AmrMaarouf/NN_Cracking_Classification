# 1. First-Time Setup (Clone & Start Working)

For team members who are downloading the repository for the first time.

### Clone the repository
git clone https://github.com/AmrMaarouf/NN_Cracking_Classification.git

### Navigate to project directory
cd NN_Cracking_Classification

### Create your personal branch
git switch -c feature/YOUR-NAME

### Verify current branch
git branch

# 2. Push Changes to Your Personal Branch

After finishing your work:

### Check modified files
git status

### Stage changes
git add .

### Commit changes
git commit -m "Add CNN model implementation"

### Push your branch to GitHub
git push -u origin feature/YOUR-NAME

# 3. Start a New Task (Update Your Local Main)

Before starting a new feature, synchronize your local repository with the latest changes.

### Switch to main
git switch main

### Get latest updates
git pull origin main

### Create a new branch
git switch -c feature/NEW-FEATURE

# 4. Create a Pull Request (PR)

### 1- Push your branch to GitHub.

### 2- Open the repository.

### 3- Click Compare & pull request.

### 4- Set the base branch to main.

### 5- Set the compare branch to your personal branch.

### 6- Add a descriptive title and description.

### 7- Click Create pull request.

### 8- Wait for review and approval before merging.
